## 维护与复现

从项目根运行，当前构建入口为工具/构建/当前/build.cjs；参数--write写入.cache/build，省略时计算和校验候选。装配输入为卡片源码/装配/manifest.json与当前/module-sources.json，源指纹与输出身份见.cache/mirror220/build.json。

2. node 工程文件/工具/构建/当前/build.cjs --write
3. node 工程文件/工具/构建/预设/paired.cjs --write
