# 酒馆卡 3.0.0 交接（2026-11-01）

目的：把网页端这一轮更新收敛成**酒馆版 3.0.0 角色卡**交付。作者已拍板三个决定：①配套预设名升 **V0.13**；②Suite 的 motion 修复**随本次发 0.4.1**；③老玩家升级走**卡内更新**（需升级清单）。

## 背景一页话

网页端今天上线到 b98319a3（issue #28 全链收官）。**卡片源码自 2.3.33 交付后零改动**（git 可证：卡片源码只有初始 import 提交）。今天与酒馆卡相关的变更只有两处：build.cjs 版本常量 2.3.33→3.0.0；paired.cjs 预设适配层三笔（squash_system_messages=true、argon压制尾部 3beb259e… 关、快速思维链 64f1335c… 开）。网页引擎的修复（开局结构/转储 user/宽容校验/存档热更弹窗/role-class）全部是网站引擎专属，**酒馆卡不需要移植**。

## 实现步骤（按序）

1. **配套预设升 V0.13**：`工程文件/工具/构建/预设/paired.cjs` 里 `name:'Izumi_东京都2051改版V0.12'` 改为 V0.13（reborn profile 的名字按同理处理，如沿用则不动）。冻结原版（`原版/Izumi-1022.json`、`原版/喵赛亚-1.5.json`）有 sha256 锁，**不能动**。
2. **重建配套预设**：跑 paired.cjs 的 write 模式（参考 `工程文件/网页独立版/tools/content-build.mjs` 第 18 行的调用方式），产物落在 `工程文件/.cache/build/`。**验收三点**：`squash_system_messages==true`；prompt_order 中 `3beb259e-7516-41c9-8657-fd56cac8e628`（argon尾部）enabled==false；`64f1335c-52cd-4d6c-93d1-77cc99b0c76c`（快速思维链）enabled==true。当前 `.cache/build/Izumi_*.json` 是旧的（build.json 回执里没有上述三笔），必须重跑。
3. **构建酒馆卡**：`node 工程文件/工具/构建/当前/build.cjs` → `工程文件/.cache/build/东京都2051-V3.0.0.json`。构建自带 schema 模板指纹校验（`数据/schema.js` 与模板漂移会构建失败——那是防呆，不是 bug）。
4. **Suite 0.4.1（已完成，f92c242 已推送）**：motion 复显修复已提交并推送（motion.mjs+manifest.json+package.json 0.4.1），主仓库子模块指针已随本批更新。接手 agent 无需再动 Suite；如需发布版 tag 由作者决定。
5. **升级清单（卡内更新）**：先 `npm install`（仓库根 package.json，acorn 等依赖）；再用 `工程文件/工具/构建/register-previous.cjs --card 工程文件/交付/当前/2.3.33-终端状态来源修复-20261025/东京都2051-V2.3.33.json --write` 把 2.3.33 登记进 `旧版来源.json`/`当前续玩来源.json`（工具已存在，会自动推导 seedRefs）；然后 `node 工程文件/工具/构建/upgrade-tool.cjs` 生成 `upgrade-manifest-3.0.0.json`（格式参照 `.cache/build/upgrade-manifest-2.3.14.json`）；用 `工具/构建/当前/upgrade-check.cjs` 与 `upgrade-browser.cjs` 验证。注意：upgrade-tool 的 acorn 依赖已改为仓库根 node_modules 解析（原硬编码本机路径已修）。
6. **打包交付**：建 `工程文件/交付/当前/3.0.0-版本统一-20261101/`（格式照抄 `2.3.33-终端状态来源修复-20261025/`）：卡 JSON + 两份配套预设 + `README.md`（安装/升级说明、SHA256、本次变更=版本号统一+配套预设思考指令修正）。同步 `交付/玩家安装与更新.md` 的现行说明指针。
7. **验证**：`工具/构建/预设/bubbles-check.cjs` 等既有检查 + isolated 酒馆验证（旧版累计更新→3.0.0、刷新续玩、正文/变量保留——2.3.13 README 的验证清单照用）+ 作者真机验收。

## 边界与注意

- 网页引擎文件（`网页独立版/src/**`）与酒馆卡**无关，不要移植**。
- 预设适配层的断言式改造（paired.cjs 的 assert/toggle）是防漂移设计：上游原版换文件会构建失败——按设计处理，不要放松断言。
- 卡内容版本语义（作者 2026-11-01 定）：兼容性热更走 3.0.x；只有改 `cxx2051-state/1` 或 `applier/1`（旧档无法继承）才升 3.1.0。本次 2.3.33→3.0.0 是纯版本统一，存档完全兼容。
- 交付物按共同规则留存本机；对外发布走仓库既定流程。
