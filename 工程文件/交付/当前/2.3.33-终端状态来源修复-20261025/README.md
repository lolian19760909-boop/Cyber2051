## 这一版改了什么（都在终端这一块，不扩到别的模块）

| 问题 | 改前 | 改后 |
| --- | --- | --- |
| 数据库镜像钩子是死代码 | `mirror236()` 只从 `parent.Mvu` 取状态，2.3.29 摘掉 MVU 后恒为空，表里永远没有行 | 改成先从 `Cxx236State.stat()` 取，只有它缺席时才退回 MVU 接口；每回合与每次终端写入后都会镜像 |
| 终端读不到状态时谎报「已发布」 | `questRecord()` 用 `rec?.state || '已发布'`，没数据也显示成可接取 | 读不到状态返回 `未就绪`（不显示接取按钮），并向诊断上报一次 |
| 每帧重复读整份状态 | `readStatData()` 每次调用都透传宿主桥，宿主桥每次把整份 stat 序列化算哈希（实测约 280 KB） | 加 120 毫秒读缓存，写入与失效事件会清掉缓存 |
| 写完状态后表还是旧的 | `updateLedger` 只写消息变量 | 写成功后触发一次数据库镜像（`CxxDataSyncRun`），让表跟上变量 |

保留 MVU 的部分：`mirror236()` 仍保留 `parent.Mvu` 作为兜底，没有把它彻底删掉；`运行时/host.js` 里「宿主是否有额外解析在跑」的探测也仍然是接口形状探测，不做硬删除。
