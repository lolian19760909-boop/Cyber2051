# 东京都2051 3.1.0

发布日期：2026-11-05

[网页版](https://cyber2051.top/play/) · [完整角色卡](https://cyber2051.top/download/东京都2051-V3.1.0.json) · [下载页](https://cyber2051.top/recent.html#download)

## 这次更新

- 生成人物和游玩时可使用开局方案，整套保存人物、出身、资金、装备与开局选项。三栏武器按九类分组查找。
- 网页支持命名保存和切换整套 API 分工方案，覆盖正文、解析、记忆等用途；选择参数随方案同步，补查次数可设为 0。标题页与创建中也可打开生成设置。
- 每个故事可为玩家及任意角色设置默认立绘、表情图和发言别名，Gal 按角色身份显示。
- 人物页新增“变量修改”：常用表单与高级 JSON 共用草稿，预览联动后保存，已保存修改可撤回。SAN 阶段随编辑结算；编辑记录留在存档中，后续模型请求使用当前游戏状态。
- 修复已保存正文后 Gal 回旧楼、数据库记忆表身份、备份导入、辅助模型协议、流式错误详情、战斗与存档面板交接，以及创角旋转布局和输入刷新。

## 网页更新

完成当前生成和保存后刷新网页，进入新版本。已有故事继续从原浏览器和账号读取；在“存档”导出完整备份可另存一份。API 方案按“在此设备记住密钥”的选择保存凭据。

## 酒馆更新

新玩家导入完整 JSON，启用酒馆助手和 Tavern Runtime Suite，按卡内入口创建人物。

3.0.0 与 2.3.33 玩家等待生成和保存结束，备份当前聊天，在卡内“卡更新”检查 3.1.0，确认并等待保存核对完成。刷新后核对最近正文、钱包、装备和任务。累计更新沿用现有卡名与故事，新增功能随完整组件更新进入。

换卡续玩时，在旧卡导出迁移存档，导入本版 JSON，在续玩入口建立副本；保留原卡、原聊天和迁移文件供核对。

验证宿主为 SillyTavern 1.19.0、酒馆助手 4.11.3、Suite 0.4.0。卡内包含规则、界面和加载脚本，宿主扩展按卡内提示启用。TT 2.4.0 的接口源码与兼容合同已核对，实体手机输入法和系统方向锁继续按实际设备体验对应。

使用龙血玄黄数据库 1.3 时沿用[数据库兼容补丁](https://cyber2051.top/download/数据库1.3-Cyber2051兼容补丁.zip)：保存聊天并关闭酒馆，备份原扩展到扩展目录以外，将包内 index.js、manifest.json 放入原扩展目录，保留其余文件，再启动刷新。每次启用一个数据库实例。
