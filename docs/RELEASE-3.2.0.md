## 这次更新

- 梦限大五人回归：千石由乃、仲町阿拉蕾、宫永野乃花、峰月律、藤都子，接入确认后的人设、相关剧情和45张立绘差分。

- 修复同一窗口保存时被误判为故事已变化的问题，保存检查与提交共用锁；检查结果在原位置更新，诊断保留具体阶段和变化字段。

新玩家导入完整JSON，按卡内提示启用酒馆助手与Tavern Runtime Suite，创建人物。

3.1.0玩家等待生成和保存结束，备份当前聊天，在卡内“卡更新”检查3.2.0，确认后等待保存核对完成。刷新并核对最近正文、人物、钱包、装备与任务。累计更新沿用原卡名与故事；本版图片资源随更新入口下载。
