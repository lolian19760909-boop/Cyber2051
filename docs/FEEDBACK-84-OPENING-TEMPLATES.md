# 完整开局方案

关联 #84 A。创建页新增“开局方案”，支持命名另存、更新、载入与删除。方案包含人物资料与上传图、出身、资金、配点、装备与装备图、游玩偏好、开场及开场选项；网页版同时保存游戏版本与玩法选择。

方案使用本地 IndexedDB 保存，网页按账号、酒馆按当前安装区分。载入将玩家选择应用到当前可编辑草稿，沿新故事自己的创建编号、人物编号与档位继续确认。完整方案的图片字节进入模板库，正式开局通过原有提交链保存图片资源。旧方案和已开始的故事可分别继续修改。

实施中补齐了三处接线：网页建档收集装备上传图并清理临时上传字段；开场档案包装层转交采集及游戏配置接口；游戏配置在模板载入时写创建草稿，在正式提交时绑定故事。准备写入失败会显示具体错误，当前人物草稿可继续操作并重试。
