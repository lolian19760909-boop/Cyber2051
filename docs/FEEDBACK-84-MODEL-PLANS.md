方案按账号与运行模式保存在本机。选择“在此设备记住密钥”时，整套正文与用途凭据随方案保存；其余凭据跟随当前浏览会话。清除密钥同时覆盖当前分工、所有命名方案和用途配置，方案名称及参数继续保留。酒馆原生正文连接与密钥继续通过宿主设置管理。

本批同时修正了四处配置机制：

- 原合并式赋值会留下前一套方案的用途、采样和思考覆盖。新增完整替换入口先校验参数，再一次更新模型配置。
- 故事恢复曾从构造时的 `input.promptOptions` 重设窗口/输出。会话现在保存当前确认的限制，普通设置编辑与方案载入均能经过恢复。
- 正文表单的“原生思考”此前没有进入配置读取，现已接齐，默认选项能清除旧强制值。
- 已选方案的普通配置写盘失败后，同页新建故事曾被磁盘旧方案覆盖。会话重建现在承接同账号当前运行配置，首次进入和换账号读取各自保存值。
