# 当前问题

网页引擎3.0.0，发布构建385ee9e2e377376a7d52。本轮改过生成主链，但没有完成酒馆全功能等价或真实模型开局验收。

## 已确认

- 宏环境漏接：请求型号为deepseek-flash，提示里的 `{{model}}` 仍可能为空；`{{charDepthPrompt}}`、`{{instructInput}}` 同样有遗漏。检查 `src/app/session.mjs`、`prompt.mjs`、`macro.mjs`，不能只测直接传入完整环境的宏函数。当前两套正式预设未用这些复现宏，不能据此认定它们造成了旧空正文。
- EJS模板未支持，遇到 `<%` 会报 unsupported_template。
- 酒馆宿主接口有限；任意插件、STScript、Quick Replies和扩展宏不具备通用运行保证。
- 世界书vectorized、automationId等字段保留了，但向量插件激活和自动化操作尚未完整接通。
- 工具、多候选、图片等结果能解码保存；自动执行工具并回填、原生候选切换、多模态全流程未完成。
- 分词在远端不可用或型号无法准确匹配时有估算回退。
- 公网网关限制：请求2MiB、响应16MiB、单账号并发2、总时限15分钟。
- 固定ST1.19的Ollama后端可能丢失同一网络块中的多行NDJSON。独立网页不经过该原生函数，酒馆接入端仍受影响。
- 原生群聊、成员轮换与静音、代写等使用方式未完成整体验收。

上述app路径均相对 `工程文件/网页独立版`。
