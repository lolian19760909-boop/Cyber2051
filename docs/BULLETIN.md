# 公告与指南

游戏主菜单的“公告与指南”打开新版窗口。普通公告继续在网站后台的“公告管理”发布；kind为card的条目进入“更新记录”。已归档条目不显示。

教程和作者来信也可通过 `工程文件/网页独立版/web/bulletin/content.json` 维护，经PR合入和部署后生效。items中每篇使用唯一id，kind为notice、update、letter或guide，并填写title、date和sections。正文按纯文本呈现；现有渲染支持段落、步骤、表格和问答。

目前提供五篇游玩指南：正文与辅助模型分工、预设与采样参数、Fish Audio、NovelAI 逐楼插图、工坊订阅。内容随对应功能维护于 content.json；作者在发布前终审文案。公告为空时，公告栏显示空态，指南栏可独立阅读。勾选“不再自动显示”只记住本次内容版本，新公告仍可自动显示；主菜单入口始终可手动打开。
