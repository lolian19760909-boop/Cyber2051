# 游戏变量修改器

关联 #85，已提交 [PR #96](https://github.com/lolian19760909-boop/Cyber2051/pull/96)。人物页新增“变量修改”，常用表单与高级 JSON 共用草稿、差异预览和正式程序提交。分支 `codex/story-variable-editor`，基于 #95 的 `fc72fce`；产品提交 `ad680be`，本批候选已完成双端验收，等待合入。

常用字段覆盖当前人物的资金、生命／耐力／RAM／SAN、成长、物品数量与装备、委托。高级编辑按人物和系统选择范围，完整游戏变量总览可只读查看。故事身份、控制权、来源和保存回执由现有保存系统维护。

编辑先预览程序校验与联动后的结果，再保存到当前故事。未保存草稿可放弃；保存失败沿同一编辑编号重试；刷新后可从已保存修改中预览并提交反向撤回。网页继续使用 program 节点与事务回执，酒馆继续使用完整楼层状态保存和磁盘读回。
