# 每个故事的角色立绘与表情差分

关联 #82，范围沿作者确认：任意角色、全部 NPC、每个故事独立保存。

人物档案新增“立绘与差分”。初始列表含玩家和全部 61 位内置角色，也可为剧情角色添加姓名和别名。每个角色有默认图及现有 9 个表情槽，支持预览、上传、清除与恢复原图。图片和别名随故事备份恢复；上传沿既有静态 WebP 处理与图片资源表，单图处理后上限 1 MiB、最长边 2048px，故事图片资源合计上限 8 MiB。

角色映射使用稳定编号；`User` 跟随所选消息楼层的扮演身份。解析缓存包含角色映射，Gal 读取本故事的图片配置。已有角色沿原图片渠道取图，自定义表情缺省时使用该角色默认图。画像配置与游戏数值分别沿现有保存责任处理。

本轮也修正了三个保存与交互问题：

- 画像提交使用会话实际读取的 revision，旧页面提交能触发现有冲突检查，保留另一页面已保存的角色配置。
- 同一请求已经写入、随后界面刷新失败时，按保存编号和故事归属确认原回执；修订号变化后仍可完成确认。
- 别名和图片容量在请求固定之前检查；填写错误时可以直接修改。已发起的保存保留同编号重试行为。
